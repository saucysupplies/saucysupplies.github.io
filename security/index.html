How we work, safely

  1. Written permission first. Nothing is tested until you sign a one-page scope: what's in, what's out, the test window, and which higher-risk tests you approve.
  2. Staging where possible. We prefer a staging copy and two test accounts, so real customers and data are never touched.
  3. Controlled and logged. Rate-limited, from one fixed IP address you can allowlist, with every request logged. You can stop the test at any time.
  4. Serious issues reported the same day. If we find something critical, we stop and tell you straight away instead of waiting for the report.
  5. Your data stays yours. Findings are shared only with you, test data is encrypted, and everything is deleted 30 days after the report.

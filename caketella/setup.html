Putting your festive game to work

A setup guide for the CakeTella team. No technical skills needed.

Short version: we host the game for you. You get one link and a QR poster. Share the link anywhere you already talk to customers, and redeem codes at the counter. That's it.

1. Your game link

Your game lives at one link that we provide. It works on any phone or computer, with no app download. The same link switches from the Christmas version to the CNY version on the date you choose. You don't need to do anything.

2. Where to share it (pick any)

  • Instagram: put the link in your bio, or add it to a Story with the "Link" sticker ("Play & win a CakeTella voucher!").
  • WhatsApp: send it in your broadcast list or post it on your WhatsApp Status. Customers who order on WhatsApp can play while they wait.
  • Facebook / TikTok: post a short screen recording of the game with the link in the caption or bio.
  • In the shop: print the QR poster we send and put it at the counter. Add the small QR sticker to cake boxes so customers play at home and come back.

3. Redeeming rewards

  1. The customer shows their code on screen (or a screenshot), for example TELLA-CNY-SILVER.
  2. Your staff checks the tier name in the code (RED / SILVER / GOLD) and applies the matching reward.
  3. Winners can also tap Order on WhatsApp, which opens a chat with your number (+6010-397 6687) with the code already typed in.
  4. Online orders: ask customers to paste the code in their WhatsApp order message.

Suggested rules (you decide): 18+ only, one code per order, valid until the date shown on the poster, cannot be combined with other promos.

4. Changing rewards, colours or dates

Just reply to our email with what you want, for example "Gold = free slice instead" or "end on 28 Feb". We update the game the same day, and the link stays the same.

5. Want it on your own website instead? (optional)

If you have a website, your web person has two easy options:

Option A: a button. Add a button or menu item called "Play & Win" that links to your game link.
Option B: show it inside a page. Paste this code into any page (replace the link with yours): 
<iframe src="YOUR-GAME-LINK" style="width:100%;max-width:420px;height:760px;border:0" title="CakeTella festive game"></iframe>
Option C: host it yourselves (after launch). Once the game is purchased, we can hand over the final single-file version (index.html) for your web person to upload. No installation, database or app store needed.

6. Timeline

  • Now to 26 Dec: Christmas version (presents and coal).
  • 27 Dec to Chap Goh Mei: CNY version (ang pao and firecrackers).
